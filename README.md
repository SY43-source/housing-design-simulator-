# 반도체 클러스터 신도시 주거설계 시뮬레이터

연령대별 인구 유입에서 **평형·방 수·점유형태 배합**과 **연도별 필요 세대수**를 역산하는 도구입니다.
모수는 평택 고덕 실측(통계청 KOSIS · 국토교통부 실거래 · 단지 메타) 기반입니다.
