# Housing Design Simulator

Works backwards from an age-inflow profile to the unit-size mix, room-count mix, tenure split, and the number of units needed per year. Parameters are calibrated on observations from Godeok New Town, Pyeongtaek (Statistics Korea, Ministry of Land transaction data, and complex metadata).

▶ **Run it: [https://sy43-source.github.io/housing-design-simulator-/](https://sy43-source.github.io/housing-design-simulator-/)**

- A single HTML file. No server, no build step, no external libraries — it works offline.
- This tool accompanies a study of whether housing built beside a semiconductor cluster fits the population that moved in: **[semiconductor-city-housing](https://github.com/SY43-source/semiconductor-city-housing)** — manuscript, analysis code, and the evidence map behind every figure.
